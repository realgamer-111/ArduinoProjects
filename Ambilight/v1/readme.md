# Funktion
Hyperion nimmt die Bildränder deines Ausgewählten Bildschirmes und Sendet sie über USB an den Arduino.
Dieser Übersetzt die Anweisungen mit meinem Code in Signale, die vom Adressierbaren LED-RGB-Streifen gelesen werden können.
